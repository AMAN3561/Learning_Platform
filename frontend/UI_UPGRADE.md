# UI Upgrade

This version upgrades the frontend without changing the backend API contract.

## Added
- Persistent light/dark theme toggle using localStorage and system preference
- Sticky glass navigation with mobile menu
- Scroll progress indicator and back-to-top button
- IntersectionObserver-powered reveal animations with reduced-motion support
- Premium hero/dashboard preview and responsive landing-page sections
- Bento feature section, learning journey, CTA and improved testimonials
- Redesigned course cards with rating, category chip and richer hover states
- Course catalog category filtering and price/popularity sorting
- Refined dashboard sidebar and role-aware navigation
- Full dark-theme styling across forms, dashboard, course pages and footer
- Responsive polish for desktop, tablet and mobile

## Run
```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
